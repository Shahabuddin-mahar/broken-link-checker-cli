# 🔗 Broken Link & HTTP Status Auditor CLI

[![Python](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Audit any website for dead 404 links, timeout errors, and redirect loops to maintain optimal SEO rank.

## 🚀 Quick Usage
```bash
python link_checker.py --url https://yourwebsite.com --output report.csv
```
